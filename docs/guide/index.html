Download, extract, install

Download your platform's ZIP and matching SHA-256 file from GitHub Releases. Verify the checksum, extract the ZIP, then run its installer. Python 3.12 is recommended; 3.11.8 or newer is required. Git is unnecessary for download releases.

Linux x64 · Ubuntu 24.04 recommended

bash ./install.sh
~/OpenEdit/OpenEdit.sh

Windows 10/11 x64 · PowerShell

powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
& "$env:USERPROFILE\OpenEdit\OpenEdit.cmd"

The installer creates a private Python environment, downloads checksum-verified Node 24 and FFmpeg/MLT runtimes, and sets up the locked graphics worker and Chromium. It tests actual editing, a transition, an animated overlay, preview, export and reopening before reporting success.

Windows setup can install Python through winget. Debian/Ubuntu setup requests administrator access for Python venv and media/browser system libraries. Other Linux distributions need equivalent prerequisites. Projects stay separate under ~/OpenEditProjects.

Complete installation, update and uninstall instructions. macOS and ARM require source installation; tested download packages are not advertised for those platforms.

Connect your agent

The installer generates mcp.json for standard MCP hosts, opencode.json for OpenCode and codex.toml for Codex. Merge the OpenEdit entry into your host's existing settings, then reload its MCP servers. Existing agent settings are preserved.

For another project, use the installation's CLI to generate its configuration:

open_edit init /absolute/path/to/project
open_edit mcp-config --project /absolute/path/to/project --format mcp
open_edit mcp-config --project /absolute/path/to/project --format opencode
open_edit mcp-config --project /absolute/path/to/project --format codex

If the private environment is inactive, use ~/OpenEdit/.venv/bin/open_edit on Linux or %USERPROFILE%\OpenEdit\.venv\Scripts\open_edit.exe on Windows. Generated configurations use absolute paths and pin the project.

Confirm six tools appear: query_project, edit_project, run_script, trigger_render, get_render_job and cancel_render_job. Ask the agent to inspect the timeline and make an edit. Parameter help is available through the tools.

External agents use their own authentication; OpenEdit needs no provider key. Built-in chat is optional: install with --with-agent / -WithAgent, then start with --with-agent.

Verified media, clear requirements

Native Linux and Windows release checks install the actual download ZIPs into paths with spaces. They check dependency consistency, transition and animated-overlay pixels, audio/video timing, complete output decoding, project reopening and the installed UI. Each installation retains install-report.json and a rendered install-report.mp4.

open_edit doctor reports available capabilities. CPU export is provided by the downloaded runtime. Hardware encoding depends on compatible hardware and drivers. Local transcription, advanced HTML and legacy Remotion are optional additions.
