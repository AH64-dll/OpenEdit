Open Edit CRT logo — design demo

Pure inline-SVG + CSS CRT television whose screen is the letter “O”. Scanlines (repeating-linear-gradient), screen curvature (radial-gradient vignette), phosphor glow, ~10–13fps flicker, power LED, glass sheen. Colors inherit app tokens (--accent, --bg*, --text, --green); dark-first with [data-theme="light"] overrides. No images, no fonts, no JS deps.
