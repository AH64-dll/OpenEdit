OpenEdit 1.4.0 simplifies the editor around a precise timeline, AI instructions,
media, preview and export. Agents use six compact interfaces and on-demand help;
media inspection returns bounded timestamped visual references and transcript
ranges. Edits remain reversible and revision-checked.

Windows x64 and Linux x64 downloads now have checksum-verified runtime setup,
project-bound configurations for common agent hosts, and real preview/export
verification. Native Windows rendering uses the matching FFmpeg/MLT runtime.
The installer adds current editable graphics; optional transcription, built-in
provider SDKs, advanced HTML and legacy Remotion remain separate.

Preview scheduling prioritizes the playhead and reuses unaffected ranges.
Completed graphics survive frozen export snapshots, preventing repeated
composition capture on unchanged exports. OpenCode CLI editing is connected to
project MCP tools and reports actual mutations without duplicate execution.

Requirements and instructions are in INSTALL.md inside each ZIP. Model provider
access/authentication belongs to the chosen agent host; live model behavior is
not guaranteed by a passing media-pipeline test. Download targets are Windows
10/11 x64 and Linux x64; Ubuntu 24.04 is the reference Linux platform.
