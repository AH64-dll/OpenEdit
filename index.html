THREE JOBS. ONE FOCUSED WORKSPACE.

Made for directing the edit.

Preview, timeline, AI instructions, media and export. The essentials are close at hand.

01 / DIRECT

A precise, simple timeline.

Scrub to a frame, select clips or mark a region, then describe the change. Review and refine it. Undo, redo and saved editing history keep your work recoverable.

02 / UNDERSTAND

Give your agent the right context.

Retrieve timestamped frames, contact sheets and selected transcript ranges. Cached analysis and on-demand tool help reduce repeated inspection and unnecessary context.

03 / FINISH

Preview quickly. Export reliably.

Preview work starts around the playhead and reuses unchanged ranges. OpenEdit handles cuts, transitions, overlays, keyframed graphics and synchronized audio, then verifies the export.

More room for animation. Graphics supports 500 visual layers and 4,096 total nodes, including keyframes. Completed graphics are reused across matching previews and exports.

START WITH THE CURRENT EDITOR

Download. Install. Make something.

The latest source is OpenEdit 1.4.0. Download and extract the source ZIP, open a terminal in its OpenEdit-main folder, then run your platform’s installer.

Latest source ZIP ↓Check Windows / Linux releases

For packaged downloads, choose 1.4.0 or newer when available. Earlier 1.3 releases use the previous editor and setup. Current release ZIPs contain the same installers; Git is not required for either extracted ZIP.

Linux x64

Ubuntu 24.04 recommended

In the extracted folder
bash ./install.sh
~/OpenEdit/OpenEdit.sh

Debian/Ubuntu setup requests administrator access for Python venv and browser/media libraries. Other distributions need equivalent prerequisites.

Windows x64

Windows 10 / 11 · PowerShell

In the extracted folder
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
& "$env:USERPROFILE\OpenEdit\OpenEdit.cmd"

Setup can install Python through winget. Native Windows media tools are provisioned; WSL and a manual MLT build are unnecessary.

Required: Python 3.11.8+ (3.12 recommended) and Internet access for initial setup. The installer provisions pinned Node 24, FFmpeg/MLT, the graphics worker and Chromium, then tests an actual editing/export workflow.

Projects live separately under ~/OpenEditProjects. Back up the entire project, including .open_edit. macOS and ARM need source setup with their own native runtimes.

Confirm six tools appear: query_project, edit_project, run_script, trigger_render, get_render_job and cancel_render_job. Your agent gets editing context and parameter help through these tools.

External agents use their own authentication; OpenEdit needs no provider key for MCP. Built-in chat is optional. To connect another project, generate a new configuration using the installation’s CLI.

What depends on your setup?

Hardware encoding requires compatible hardware and drivers. Local transcription is optional. Advanced HTML and legacy Remotion are separate additions.

Model accuracy and billed token usage depend on your agent and provider. Media-pipeline tests verify editing/rendering; they don’t prove a live model’s creative decisions.
